# Nexoreya

AI-Powered Growth & Digital Transformation.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS v4
- Framer Motion
- Lucide React

## Local development

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Production

```bash
npm run build
npm start
```

Codex Build 01 establishes the production-oriented application shell and first homepage foundation. Future builds can extend the system with dedicated service pages, proof/case studies, lead qualification, analytics, CMS/data integrations, accessibility hardening and deployment configuration.
